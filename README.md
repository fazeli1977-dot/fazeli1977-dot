# Alireza Sani

**Civil & Environmental Engineering · Water Systems · Hydrology · Climate & Earth Observation**

I build practical engineering software for water infrastructure, environmental monitoring, and climate-risk analysis, with a focus on clear calculations and usable decision-support tools.

## Water & Civil Infrastructure

| Project | What it does |
| --- | --- |
| [Water Network Optimizer](https://github.com/fazeli1977-dot/water-network-optimizer) | Sizes pressurized water pipes, checks velocity constraints, and calculates Hazen–Williams head loss. |
| [Water Sampling App](https://github.com/fazeli1977-dot/water-sampling-app) | Persian RTL workflow for water and wastewater sampling, lab-result checks against Iranian DOE standards, and PDF reporting. |
| [WeatherXM Smart Stormwater](https://github.com/fazeli1977-dot/weatherxm-smart-stormwater) | Stormwater runoff and drainage-capacity risk demonstrator using hydrology calculations and WeatherXM observations; its dashboard currently uses demo data. |
