## Featured Project

### SAR-MotionLens — Multi-Frequency SAR/InSAR Earth-Surface Dynamics Lab

Live application: [sar-motionlens.streamlit.app](https://sar-motionlens.streamlit.app/)

An interactive platform for exploring Earth-surface dynamics across X-, C- (Sentinel-1), and L-band (NISAR/ALOS-4) SAR. Select a location to generate interferograms, displacement and PolSAR time series, machine-learning regime classification, anomaly scoring, and subsidence-risk classes, with downloadable GeoJSON and PDF reports. Real NISAR granule metadata is queried live from the ASF DAAC public API.

> Data transparency: the deformation, interferogram, time-series, and machine-learning outputs are physically motivated simulations for the selected point. NISAR granule metadata comes from the real ASF DAAC API. Simulated analytical results are not actual satellite-derived deformation measurements.

Repository: [fazeli1977-dot/SAR-MotionLens](https://github.com/fazeli1977-dot/SAR-MotionLens)
